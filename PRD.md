# ClipCut — Product Requirements Document

> Документ для людей и ИИ-агентов, работающих с кодовой базой ClipCut. Описывает, ЧТО продукт делает и ЗАЧЕМ. Для описания того, КАК устроена система технически, см. [ARCHITECTURE.md](ARCHITECTURE.md).

## 1. Что это за продукт

ClipCut — Telegram-бот, который превращает длинные видео (YouTube, Twitch, Google Drive, произвольные ссылки) в короткие вертикальные ролики («шортсы») для TikTok/YouTube Shorts/Instagram Reels. Пользователь присылает боту ссылку, выбирает параметры оформления, и бот автоматически:

1. находит в видео потенциально виральные фрагменты,
2. вырезает их,
3. монтирует в выбранный формат (раскладка, фон, субтитры, трекинг лица),
4. присылает готовые ролики прямо в чат.

Продукт монетизируется по модели pay-per-generation: у пользователя есть баланс «генераций» (1 генерация = 1 запуск обработки одной ссылки, в результате которого создаётся пакет шортсов).

## 2. Целевая аудитория

- Контент-мейкеры, стримеры, подкастеры — хотят нарезать длинные эфиры/интервью на шортсы без монтажёра.
- SMM-агентства и «фабрики контента», которые массово производят шортсы для клиентов (в т.ч. добавляют свой брендированный баннер — см. `add_banner` для админов).
- Условно любой человек с ссылкой на длинное видео, желающий быстро получить вирусные нарезки.

Продукт двуязычный: интерфейс на русском и английском (`locales/ru.json`, `locales/en.json`), язык выбирается пользователем или определяется автоматически.

## 3. Ключевые пользовательские сценарии (User Journeys)

### 3.1. Первый запуск (онбординг)
1. Пользователь запускает `/start`.
2. Бот создаёт запись в БД с начальным балансом (`START_BALANCE`), опционально учитывает реферальный код (`ref_<id>`) и источник трафика (`?start=source_...`).
3. Пользователю предлагается попробовать демо-режим (готовое демо-видео, без списания баланса) — see `pricing.DEMO_CONFIG`.
4. Возможна подписка на обязательные каналы (`REQUIRED_CHANNELS`) в обмен на бонусные генерации (`REWARD_FOR_SUBSCRIPTION`).

### 3.2. Основной сценарий — генерация шортсов
1. Пользователь присылает ссылку (YouTube / Twitch / Google Drive / произвольный URL с видео).
2. Бот проверяет доступность видео (не приватное, не удалено, хватает диска на сервере) — `processing/download.check_video_availability`.
3. Пошаговый диалог настройки (Telegram inline-кнопки):
   - Количество шортсов: «Авто» или конкретное число (до `MAX_SHORTS_PER_VIDEO`).
   - Соотношение сторон: `1:1`, `16:9`, `9:16`.
   - Фоновое видео снизу («brainrot»: GTA, Minecraft, Subway Surfers и др.) — только для 1:1/16:9 с брейнротом.
   - Трекинг лица (автоматическое слежение камеры за говорящим) — доступно для форматов с вертикальной обрезкой.
   - Тип субтитров: по словам (word-by-word), по фразам, без субтитров.
   - Цвет субтитров: белый/жёлтый/фиолетовый/зелёный.
   - (Только для админов) Брендированный баннер поверх видео.
4. Экран подтверждения — итоговая конфигурация + текущий баланс, кнопки «Подтвердить»/«Отклонить».
5. При подтверждении задача становится в очередь на обработку (БД + in-memory очередь), баланс списывается только при успешном результате.
6. Пользователь получает статус-обновления в процессе, затем — готовые видео по одному, с подписью (заголовок-хук, тайм-код, оценка виральности 1–10).
7. После получения всех роликов — запрос оценки (1–5 звёзд) и опциональный текстовый фидбек.

### 3.3. Пополнение баланса
1. `/topup` или кнопка «Пополнить баланс».
2. Выбор пакета генераций (`pricing.PACKAGES`, фиксированные тарифы 1/5/10/25/50 генераций).
3. Выбор способа оплаты: Telegram Stars, CryptoBot (USDT), ЮKassa (карта/СБП, только RUB).
4. Подтверждение оплаты → баланс пополняется автоматически.
5. Реферальная механика: у приглашённого пользователя может быть разовая скидка; при первом пополнении рефереру начисляется бонус (`REFERRER_REWARD`).

### 3.4. Обратная связь и модерация
- Пользователь может дизлайкнуть ролик → пересылается модераторам с кнопками «ок»/«проблема», при подтверждении проблемы — автоматический возврат генерации.
- Текстовый фидбек после оценки пересылается в отдельную группу, админ одобряет/отклоняет, при одобрении пользователь получает бонусные генерации (`REWARD_FOR_FEEDBACK`).

### 3.5. Административные функции
Доступны пользователям из `ADMIN_USER_IDS`:
- Начисление/установка баланса пользователю (`/addgenerations`, `/setbalance`).
- Массовые рассылки: всем пользователям, с прайсами и кнопкой покупки, целевой рассылке по списку ID.
- Временные скидки (`/start_discount`, `/end_discount`).
- Удаление пользователя, экспорт всех пользователей в CSV.
- Добавление брендированного баннера на видео при генерации.

## 4. Продуктовая модель / бизнес-логика

### 4.1. Монетизация
- Валюта продукта — «генерация» (1 запуск = 1 списание при успешном результате, независимо от числа полученных шортсов из одной ссылки).
- Тарифная сетка (`pricing.py`, все суммы указаны в RUB, конвертируются в USDT/Stars по фиксированному курсу):

  | Генераций | Обычная цена | Цена по скидке |
  |---|---|---|
  | 1 | 149 ₽ | 69 ₽ |
  | 5 | 449 ₽ | 299 ₽ |
  | 10 | 799 ₽ | 449 ₽ |
  | 25 (популярный) | 1790 ₽ | 990 ₽ |
  | 50 | 2590 ₽ | 1490 ₽ |

- Три платёжных провайдера: Telegram Stars (нативные платежи Telegram), CryptoBot (USDT), ЮKassa (карты/СБП, требует email для чека).
- Списание генерации происходит только при успешной обработке (`shorts_generated_count > 0`); если процесс завершился ошибкой — баланс не трогается.
- Есть глобальные и реферальные временные скидки.

### 4.2. Логика выбора «виральных» моментов
Приоритет стратегий выбора фрагментов (см. `processing/bot_logic.get_highlights`):
1. **Heatmap YouTube** («Most Replayed») — если доступен, самый приоритетный и дешёвый по ресурсам способ: моменты с наибольшей плотностью повторных просмотров.
2. **GPT-анализ транскрипта** — если heatmap недоступен, транскрипт (субтитры YouTube или Whisper) отправляется в GPT (через файловое хранилище + file_search) с чёткими требованиями к длительности, завершённости мысли и «виральности».
3. **Случайные фрагменты (fallback)** — если и GPT не сработал (нет транскрипта, ошибка API), нарезаются случайные непересекающиеся отрезки допустимой длины.

Каждому фрагменту присваивается `virality_score` (1–10), фрагменты сортируются по убыванию и присылаются пользователю в этом порядке.

### 4.3. Ограничения и константы продукта
- Длительность одного шортса: `MIN_SHORT_DURATION=55с` – `MAX_SHORT_DURATION=90с`.
- Максимум шортсов за одну генерацию: `MAX_SHORTS_PER_VIDEO=15`.
- Требуется минимум `FREESPACE_LIMIT_MB=3000` МБ свободного места на диске сервера для старта обработки (видео скачивается на сервер целиком в 1080p перед нарезкой, поэтому запас должен покрывать размер полного файла).
- Обработка идёт в фоновой очереди с ограниченным числом параллельных воркеров (`MAX_CONCURRENT_TASKS`), задачи переживают перезапуск бота (персистятся в SQLite).

### 4.4. Поддерживаемые платформы-источники видео
- YouTube (полная поддержка: heatmap, субтитры, аудио, сегментное скачивание).
- Twitch (VOD) — только случайная нарезка (нет heatmap/субтитров YouTube), с Whisper-транскрипцией для субтитров на выходе.
- Google Drive / произвольные прямые ссылки на видео — общий workflow, аудио извлекается напрямую, транскрипция через Whisper.

## 5. Продуктовые форматы вывода

### 5.1. Раскладки (layout)
| Layout | Соотношение | Описание |
|---|---|---|
| `square_center` | 1:1 | Видео по центру квадратного канваса, чёрные поля |
| `square_top_brainrot_bottom` | 1:1 | Верх — основное видео (60%), низ — фоновое brainrot-видео |
| `full_center` | 16:9 | Видео по центру вертикального канваса 9:16 |
| `full_top_brainrot_bottom` | 16:9 | Верх/низ 50/50, основное видео + brainrot |
| `face_track_9_16` | 9:16 | Вертикальная обрезка на всю высоту, с опциональным трекингом лица |

### 5.2. Фоновые «brainrot»-видео
Библиотека геймплейных видео для отвлечения внимания/удержания (GTA, Minecraft паркур, Subway Surfers, Slither.io, Forza, Bouncing Balls, Ball Escape) — хранятся в `keepers/`, не в git (доставляются отдельно на сервер).

### 5.3. Субтитры
- Типы: по словам (караоке-эффект), по фразам, отключены.
- Цвета: белый, жёлтый, фиолетовый, зелёный.
- Технически — ASS-субтитры, вжигаются в видео через ffmpeg.

### 5.4. Трекинг лица
Опциональная функция для вертикальных форматов — камера «следует» за говорящим (детекция через Haar cascade, сглаженное перемещение точки обрезки). При отсутствии лиц — fallback на центральную обрезку.

## 6. Аналитика и метрики продукта

Все ключевые продуктовые события логируются в ClickHouse (см. [ANALYTICS_EVENTS.md](ANALYTICS_EVENTS.md) — источник истины по событиям) и визуализируются в Yandex DataLens. Ключевые воронки, которые продукт отслеживает:

- **Воронка конфигурации**: от `config_video_url_provided` до `generation_queued`/`config_cancelled` — на каком шаге настройки пользователи отваливаются.
- **Воронка генерации**: `generation_start` → `generation_success`/`generation_error`.
- **Воронка пополнения**: `topup_start` → `topup_package_selected` → `topup_method_selected` → `payment_success`.
- **Удовлетворённость**: `rating` (1–5) + опциональный `feedback`.
- Каждая сессия конфигурации/генерации имеет сквозной `generation_id`, каждая оценка — `rating_id`, связывающий рейтинг с текстовым отзывом.

При внесении изменений в продуктовую логику (шаги диалога, ценообразование, конфиг генерации) — обновляй `ANALYTICS_EVENTS.md`, если это влияет на состав или структуру событий.

## 7. Локализация

- Полностью двуязычный интерфейс: `locales/ru.json`, `locales/en.json` — плоские key-value словари, доступ через `localization.get_translation(lang, key)`.
- Язык хранится в БД на пользователя (`users.language`), по умолчанию `ru`.
- При добавлении новых пользовательских сообщений — всегда добавлять ключ в оба файла локализации, никогда не хардкодить текст в коде хендлеров.

## 8. Не входит в скоуп (на момент написания документа)

- Нет собственного веб-интерфейса/личного кабинета — всё взаимодействие только через Telegram.
- Нет ручного редактирования нарезанных фрагментов пользователем (только выбор пресетов оформления до генерации).
- Нет поддержки платформ кроме YouTube/Twitch/Google Drive/прямых ссылок.
- Нет подписочной модели — только разовая покупка пакетов генераций.
